# Jaseem Quraishi — Portfolio

Live site: [jaseem-codes.vercel.app](https://jaseem-codes.vercel.app/)

A personal portfolio built with Next.js 14 App Router, TypeScript, Tailwind CSS, and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

Production build and start:

```bash
npm run build
npm start
```

Type check:

```bash
npm run typecheck
```
